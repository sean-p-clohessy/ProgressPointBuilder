# QA checklist

## Interface

- [ ] Light mode has sufficient contrast and visible focus states.
- [ ] Dark mode has sufficient contrast and distinguishable controls.
- [ ] Theme follows the system initially and a manual choice persists.
- [ ] Layout works at 1440×900, 1280×720, 1024×768, 768×1024, and 390×844.
- [ ] No horizontal scrolling or clipped labels.
- [ ] All controls are reachable and operable by keyboard.
- [ ] Screen-reader labels and heading order are logical.
- [ ] Reduced-motion preference is respected.

## Inputs and report workflow

- [ ] Standard, custom, singular-they, and name-only pronouns work.
- [ ] Mixed ratings remain valid and are described coherently.
- [ ] Percentages from 0 to 100 are handled naturally.
- [ ] Generated text remains editable.
- [ ] Copy, restore, regenerate, clear, and reset behave safely.
- [ ] Manual edits are never overwritten without confirmation.

## Engine and privacy

- [ ] Identical input and variation index give identical output.
- [ ] Controlled regeneration changes wording without changing meaning.
- [ ] Reports work offline.
- [ ] No external requests, remote fonts, analytics, AI, or APIs exist.
- [ ] No learner data is written to browser storage or logs.
- [ ] Spelling, grammar, punctuation, and rating alignment are checked.
